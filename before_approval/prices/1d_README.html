Main Keypoints

This document outlines the strategy for merging the price forecast at the individual hotel level with that of each respective city, using all available hotels for: i) that same city, ii) the same number of hotel stars, and iii) using the same currency.

The folder and its respective contents are structured in the following way:

→ code subfolder contains any code scripts, currently all under the forecast_prophet_all_hotels_plus_cities_stars_dates_2025.ipynb notebook.

→ data subfolder contains any input/other data. This consists of both the historic and forecasted data at the individual hotel and city (per stars per currency) level input data containing the daily forecasted prices as calculated in the previous steps, and any auxiliary lookup files (under the data/lookups folder one level down).

→ out subfolder contains any output data. In it, all figures can be found in both aggregated single multipage .pdf (light-weight), individual .png file, or individual .html file formats (much heavier weight, but easier to parse and navigate through).

→ docs subfolder contains any documentation for the present analysis. Start with the respective README.html file.
